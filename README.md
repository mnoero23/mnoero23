## Sobre mí

Soy analista de datos con experiencia en administración, contratos y operaciones dentro de la industria Oil & Gas. Mi recorrido profesional me permite combinar criterio de negocio, análisis financiero y herramientas de datos para resolver problemas reales de forma simple y práctica.

Actualmente profundizo mi formación en Data Science y desarrollo proyectos orientados a:

- automatización y mejora de procesos;
- análisis financiero y comercial;
- tableros para seguimiento de indicadores;
- modelos predictivos y aprendizaje automático;
- soluciones de datos para pymes y equipos operativos.

> **Mi enfoque:** encontrar una forma simple de resolver problemas con datos.
